# Set up the unit converter

Nothing to set up: no accounts, keys or internet access.

## Try it

1. Say: "How many kilometres is 26.2 miles?"
2. Piyo loads the skill and asks to run its script `convert.py`. Because you installed this skill, Piyo asks you
   to approve the script each time. Approve it.
3. Piyo answers with the exact result.

## What this skill can do

- Run its own `convert.py` script, which only does arithmetic on the numbers it is given.
- The script runs in its own Python environment with no network access and a 10 second limit.
