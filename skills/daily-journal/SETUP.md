# Set up the daily journal

## Choose a folder

1. Open **Settings > Folders** and add the folder where you want your journal files (for example `Documents/Journal`).
2. Leave "no prompts for changes" off at first. Piyo then asks before each file it writes, so you can see what
   it saves.

## Try it

1. Say: "Journal today: finished the report, went for a run, tired but happy."
2. Piyo shows the entry. Approve the save and check the new `journal-<date>.md` file in your folder.

## What this skill can do

- List, read and write files in the folders you approved. Nothing else.
- It needs no accounts, keys or internet access.
