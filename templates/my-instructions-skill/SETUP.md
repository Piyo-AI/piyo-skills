# Set up the meeting notes skill

Nothing to set up: no accounts, keys, folders or internet access.

## Try it

1. Paste some meeting notes into Piyo and say: "Give me the decisions and action items."
2. Piyo answers with a Decisions list and an Actions list. Anything the notes do not say is marked, not guessed.

## What this skill can do

- It reads only what you paste into the chat. It uses no tools, so it cannot open files or the web.
